# Chrome Lens v1.1 - LLM Debugging Implementation Guide

## Overview

This guide provides step-by-step instructions for implementing the v1.1 LLM debugging features. Follow the phases in order, using TDD methodology for each task.

## Implementation Phases

### Phase 16: Real-time Code Modification (Priority: HIGH)

#### Task 16.1: Add modify_source_code Tool Definition

**Objective**: Define the tool schema for real-time source code modification.

**Test First (RED)**:
```typescript
// tests/unit/task-16.1.test.ts
describe('modify_source_code tool definition', () => {
  it('should include modify_source_code in available tools', async () => {
    const tools = await server.listTools();
    const tool = tools.find(t => t.name === 'modify_source_code');
    expect(tool).toBeDefined();
    expect(tool.inputSchema).toMatchObject({
      type: 'object',
      properties: {
        tabId: { type: 'string' },
        sourceId: { type: 'string' },
        newContent: { type: 'string' },
        hotReload: { type: 'boolean' },
        validateSyntax: { type: 'boolean' }
      }
    });
  });
});
```

**Implementation (GREEN)**:
1. Add tool definition to `toolDefinitions` array in `server.ts`
2. Include proper JSON schema with all parameters
3. Add description explaining the tool's purpose

**Environment Variables**:
- `CODE_MODIFICATION_ENABLED` - Enable/disable feature
- `HOT_RELOAD_TIMEOUT` - Timeout for hot reload operations

#### Task 16.2: Implement Source Code Discovery and Targeting

**Objective**: Discover modifiable source files and enable precise targeting.

**Test First (RED)**:
```typescript
// tests/unit/task-16.2.test.ts
describe('Source code discovery', () => {
  it('should discover JavaScript source files', async () => {
    const sources = await server.discoverSourceFiles(mockTabId);
    expect(sources).toContainEqual(
      expect.objectContaining({
        scriptId: expect.any(String),
        url: expect.stringContaining('.js'),
        hasSourceMap: expect.any(Boolean)
      })
    );
  });

  it('should resolve source maps for targeting', async () => {
    const target = await server.resolveSourceTarget('app.ts', mockTabId);
    expect(target.scriptId).toBeDefined();
    expect(target.originalSource).toBe(true);
  });
});
```

**Implementation (GREEN)**:
1. Enable Debugger domain: `await client.send('Debugger.enable')`
2. Listen for `Debugger.scriptParsed` events
3. Build source file registry with script IDs and URLs
4. Implement source map resolution logic

#### Task 16.3: Implement Real-time Code Modification Engine

**Objective**: Modify source code with immediate effect in browser.

**Test First (RED)**:
```typescript
// tests/unit/task-16.3.test.ts
describe('Code modification engine', () => {
  it('should modify source code and trigger hot reload', async () => {
    const result = await server.modifySourceCode({
      tabId: mockTabId,
      sourceId: 'script123',
      newContent: 'console.log("modified");',
      hotReload: true

    expect(result.reloadRequired).toBe(false);

      'Debugger.setScriptSource',
      expect.objectContaining({ scriptId: 'script123' })
    );
  });
});
```

**Implementation (GREEN)**:
1. Use `Debugger.setScriptSource` for in-memory modification
2. Implement hot reload strategies (module.hot, location.reload)
3. Handle rollback on failure
4. Track affected modules

## Common Patterns

### CDP Method Invocation

```typescript
async function cdpOperation(client: CDPClient, tabId: string) {
  try {
    const result = await client.send('Domain.method', {
      // parameters
    });
    return { success: true, data: result };
  } catch (error) {
    return { success: false, error: error.message };
  }
}
```

### Event Handling

```typescript
class EventMonitor {
  constructor(private client: CDPClient) {
    this.client.on('Domain.event', this.handleEvent.bind(this));
  }
  
  private handleEvent(params: any) {
    // Process event
    this.emit('processed', processedEvent);
  }
}
```

### State Management

```typescript
class DebugState {
  private state = new Map<string, any>();
  
  update(tabId: string, data: any) {
    this.state.set(tabId, {
      ...this.state.get(tabId),
      ...data,
      lastUpdated: Date.now()
    });
  }
}
```
