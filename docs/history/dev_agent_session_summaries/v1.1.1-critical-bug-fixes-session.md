## Challenges and Solutions

1. **Jest/import.meta Compatibility**:
   - Problem: Jest doesn't support import.meta syntax
   - Solution: Created `server-cli.ts` to separate CLI concerns

2. **TypeScript Compiler Integration**:
   - Problem: createProgram approach caused errors
   - Solution: Switched to createLanguageService for better integration

3. **Concurrent DOM Operations**:
   - Problem: Race conditions with multiple DOM.enable calls
   - Solution: Implemented Promise-based synchronization

4. **Source Map Detection in Tests**:
   - Problem: Async detection timing issues
   - Solution: Moved detection to getErrorHistory for synchronous access
