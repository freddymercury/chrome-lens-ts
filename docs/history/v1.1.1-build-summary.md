## Deployment Notes

1. **Node.js Version**: Requires Node.js 22.x or higher
2. **Chrome Setup**: Chrome must be running with `--remote-debugging-port=9222`
3. **Environment**: Copy `.env.example` to `.env` and configure
4. **Dependencies**: Run `npm install` before first use
