# Chrome Lens v1.2 Release Notes

## 🚀 Quick Summary
- **Version**: 1.2.0
- **Release Date**: June 2025
- **Major Feature**: Intelligence Layer with AI-driven debugging strategies
- **New Tool**: `suggest_debugging_strategy` (19 tools total)
- **Compatibility**: Fully backward compatible with v1.1.1
- **Optional**: Claude AI integration for enhanced analysis

## Overview
Chrome Lens v1.2 introduces the Intelligence Layer, bringing AI-driven debugging strategies to the Chrome DevTools MCP Server. This release builds upon the solid foundation of v1.1.1 with new capabilities for intelligent debugging assistance.

## New Features

### 🧠 Intelligence Layer
- **AI-Driven Debugging Strategies**: New `suggest_debugging_strategy` tool that analyzes problems and suggests optimal debugging approaches
- **Problem Categorization**: Automatic classification of issues (runtime errors, performance, logic errors, network, security)
- **Strategy Templates**: Pre-built debugging workflows for common problem types
- **Confidence-Based Ranking**: Strategies ranked by likelihood of success
- **Context-Aware Suggestions**: Leverages current tab state and monitoring data

### 📊 Event System Enhancement
- **Pure Event Streaming**: Real-time event streaming architecture
- **Multiple Concurrent Streams**: Support for parallel event monitoring
- **Advanced Filtering**: Filter by type, severity, URL patterns, custom functions
- **Buffering & Throttling**: Configurable event buffering and rate limiting
- **Stream Statistics**: Detailed metrics on event streams

### 🗄️ State Management Layer
- **Centralized State**: Single source of truth for all Chrome Lens state
- **Event Sourcing**: Complete history of all state changes
- **Time Travel Debugging**: Reconstruct state at any point in time
- **State Snapshots**: Save and restore debugging sessions
- **Session Management**: Track debugging sessions with metrics

## Tool Count

## Usage Example

```javascript
// Get AI-driven debugging suggestions
const response = await chrome_lens.suggest_debugging_strategy({
  problemDescription: "TypeError: Cannot read property 'name' of undefined",
  strategyType: "step-by-step", // optional: step-by-step, exploratory, targeted
  confidence: 0.7,              // optional: minimum confidence threshold
  maxSteps: 5,                  // optional: maximum steps in strategy
  tabId: "A1B2C3D4...",        // optional: include tab context
  includeHistory: true          // optional: use historical data
});

// Response includes:
// - Categorized problem (type, subtype, confidence)
// - Ranked debugging strategies with steps
// - Estimated time and complexity
// - Context-aware tool parameters
```

## Installation & Setup

### Prerequisites
1. Node.js 22.x or higher
2. Chrome with remote debugging enabled
3. Claude Desktop (for MCP integration)

### Installation Steps
```bash
# 1. Clone or update repository
git clone https://github.com/yourusername/chrome-lens-ts.git
cd chrome-lens-ts

# 2. Install dependencies
npm install

# 3. Build the project
npm run build

# 4. Start Chrome with debugging
google-chrome --remote-debugging-port=9222 --user-data-dir=/tmp/chrome-debug
```

### Claude Desktop Configuration
Add to your `~/Library/Application Support/Claude/claude_desktop_config.json`:
```json
{
  "mcpServers": {
    "chrome-lens-ts": {
      "command": "/bin/bash",
      "args": ["/path/to/chrome-lens-ts/start-chrome-lens.sh"],
      "env": {
        "CHROME_DEBUG_PORT": "9222",
        "CHROME_DEBUG_HOST": "localhost",
        "LOG_LEVEL": "info",
        "ANTHROPIC_API_KEY": "your-api-key-here",
        "CLAUDE_ANALYSIS_ENABLED": "true",
        "CLAUDE_MODEL": "claude-3-opus-20240229",
        "CLAUDE_MAX_TOKENS": "1000"
      }
    }
  }
}
```

## Migration Guide

### From v1.1.1 to v1.2
1. No breaking changes - v1.2 is fully backward compatible
2. Pull latest code and rebuild:
   ```bash
   git pull
   npm install
   npm run build
   ```
3. Optional: Add Claude integration environment variables
4. Restart Claude Desktop
5. New `suggest_debugging_strategy` tool will be available
